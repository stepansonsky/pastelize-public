# Pastelize Privacy Policy
Last Updated: February 7, 2026

We value your privacy. This policy explains how we handle your data — which, in short, is as little as possible.

## Data Collection and Usage
Pastelize does not collect personal information (such as your name, email, or contact list). We only collect non-personally identifiable technical data for the following purposes:

### Crash Logs
If the app crashes, we receive technical details about the error so we can fix it.

### Device Compatibility
We collect basic device information (e.g., model and OS version) to ensure the app performs well on your specific hardware.

## Third-Party Services
We use industry-standard analytics tools (such as Google Analytics and Google Firebase Crashlytics) to process the technical data mentioned above. These services do not receive any information that could be used to identify you personally.

## Consent
By using Pastelize, you consent to this Privacy Policy.

## Contact Us
If you have any questions regarding this policy, please contact us using Google Play Store.
